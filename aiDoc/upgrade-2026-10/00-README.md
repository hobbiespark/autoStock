## 핵심 결론 10가지

1. **무인 운영에 P0 결함 3건**: 미체결 타임아웃 취소가 사실상 동작하지 않음(ACCEPTED 미대상), 재기동 시 킬스위치·일 손실이 풀림(메모리 상태), 공시 블랙리스트 삭제가 트랜잭션 밖 — Phase 0에서 먼저 막는다.
2. **키움 REST의 새 단일 장애점**: 허용 IP 등록 필수(10개, IP 바뀌면 `8010`), **3개월 미접속 자동 해지 — 접속 기준은 실서버, 모의만 쓰면 해지될 수 있음**(공식 안내). 9/18 키 무효화 장애의 유력 원인 후보.
3. **백테스트≠라이브**: C3 판단 주기가 라이브는 21역일, 백테스트는 21거래일이고, 재기동마다 전 종목을 재판단한다 — 게이트 ② 격차 계측이 오염된다.
4. **운영자 오조작**: 실주문 경로인 테스트 시그널이 1클릭·자동 사이징(193주 사고 원인), 명령 실패는 화면에 안 보인다.
5. **전략**: 21계열 FAIL과 최신 문헌이 같은 방향(지수 1종 볼타겟은 비용이 이득 상쇄, 시총가중 우위 구간은 5~12년). 단 코어 KODEX200은 삼성전자+SK하이닉스 ≈60% 집중이라 **2026-07~09 −22%**(동일가중은 +2%) — ADR-15에서 **코어 비중을 MDD 예산으로 정해야 한다**(D-01).
6. **LLM**: 백테스트는 학습 컷오프 이전 구간이 오염되어 전진(모의) 검증만 유효, 감성 정확도 ≠ 수익 → **비매매 해설부터**(D-10). 비용은 월 수 달러 수준.
7. **플랫폼**: Boot 3.5 OSS 지원 종료(2026-06-30). 순서는 **Boot 4.1(Gradle 8.14) → Gradle 9.1+ → JDK 25**(Boot 3.5는 Gradle 9 미지원, JDK 25 툴체인은 Gradle 9.1+ 필요 — 조사 초안 정정).
8. **FE**: Vite 5 지원 종료, 확정 조합은 **Vite 8 + TS 6.0 + ESLint 9**(typescript-eslint가 TS <6.1, jsx-a11y가 ESLint ≤9만 지원). 접근성은 폼 레이블·키보드·라이브 리전·대비에서 불합격.
9. **인프라**: 백업·외부 감시 없음. Healthchecks.io(텔레그램 연동 공식) + 일일 pg_dump가 비용 0으로 가장 효과 큼. Docker Desktop은 로그인 없이 기동 공식 미지원 → 서비스화는 D-08.
10. **기존 결정과 충돌 13건**은 전부 "기존 결정 유지 + 보완" 또는 "사용자 결정"으로 정리했다(11 실행 계획 2절) — JNA 절전 차단 유지, CI 모의 키 유지, RestClient 전환 보류, 라우터 대신 해시 탭 등.

## 이 묶음의 근거와 한계

- **조사 방식**: 리포 문서·코드 정독(Java 209파일·FE 2,264줄), 공식 문서·릴리스 노트·npm 레지스트리·키움 공식 GitHub 스펙 JSON(2026-09-15 커밋) 직접 확인, 1차 자료가 없으면 2차 자료로 표기. 1차 조사 뒤 **보강 조사**로 미확인 항목을 다시 확인하고 본문 오류를 정정했다(각 문서의 "보강 확인·정정" 절).
- **미검증**: 이 문서 작성 중 빌드·테스트·운영 실측은 하지 않았다. "추론" 표기 항목(예: 블랙리스트 삭제 미반영, 9/18 장애 원인)은 11 실행 계획의 테스트·실측 절차로 확인한다.
- **여전히 미확인**(각 문서 말미 목록): 키움 모의 서버 점검 시간표·해외/클라우드 IP 정책·"접속" 인정 기준, 한국 팩터 논문 본문(KCI 접근 차단), KRX 금융 LLM 벤치마크 수치, 2027 휴장일(12월 공지).
- **투자 관련 서술**은 제도·통계·연구 결과의 정리이며 투자 자문이 아니다. 비중·자금 결정은 사용자가 한다.
